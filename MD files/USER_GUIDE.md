## 🎯 Как пользоваться платформой

### Для ВЛАДЕЛЬЦЕВ САЛОНОВ:

#### 1. Регистрация и вход

1. Откройте https://aurelle.uz/auth
2. Зарегистрируйтесь или войдите
3. Выберите роль "Для владельцев"
4. Заполните профиль

#### 2. Управление салоном (/owner)

**Добавление фото салона:**

Проблема которую вы описали: "в салонах не работает вложение фото"

**Текущая реализация:**

- Кнопка "Добавить фото" должна открыть диалог
- Вы вводите URL изображения (не загружаете файл!)
- Либо описание (опционально)

**API endpoints доступны:**

- `POST /api/upload/salon-photo` - загрузка одного фото
- `POST /api/upload/salon-photos` - загрузка нескольких фото

**Как должно работать:**

```
1. В кабинете владельца найдите раздел "Информация о салоне"
2. Нажмите "Фотографии"
3. Нажмите "+ Добавить фото"
4. ТЕКУЩИЙ СПОСОБ: Введите URL изображения
   - Пример: https://example.com/photo.jpg
5. Или описание изображения
6. Нажмите "Сохранить"
```

**Альтернатива (через API):**

```bash
# Загрузите файл напрямую через API
curl -X POST https://aurelle.uz/api/upload/salon-photo \
  -H "Cookie: connect.sid=ВАШ_SESSION_ID" \
  -F "image=@/путь/к/фото.jpg"

# Ответ:
# {"success":true,"url":"/uploads/salons/filename.jpg","filename":"filename.jpg"}
```

### Для КЛИЕНТОВ:

#### 1. Регистрация и вход

1. Откройте https://aurelle.uz/auth
2. Зарегистрируйтесь или войдите
3. Выберите роль "Для клиентов"
4. Заполните профиль

#### 2. Запись на услугу (/client)

**Проблема которую вы описали:** "не получается записаться на услугу"

**Как ДОЛЖНО работать:**

```
1. Найдите салон на главной странице или в /salons
2. Откройте страницу салона
3. Перейдите на вкладку "Услуги"
4. Найдите нужную услугу
5. Нажмите кнопку "Записаться"
6. Выберите дату и время
7. Выберите мастера (опционально)
8. Подтвердите запись
```

**Если не работает - проверьте:**

- Залогинены ли вы (должна быть кнопка профиля в header)
- Есть ли услуги у салона (если салон новый - услуг может не быть)
- Проверьте консоль браузера на ошибки (F12 → Console)

**API endpoint для записи:**

```
POST /api/bookings
{
  "salonId": "salon-id",
  "serviceId": "service-id",
  "masterId": "master-id", // опционально
  "date": "2026-01-05",
  "time": "14:00"
}
```

**Текущая реализация:**

```
1. Зайдите в /master
2. Найдите раздел "Мое портфолио"
3. Нажмите "Добавить фото"
4. Откроется диалог с полями:
   - URL изображения (введите ссылку на фото)
   - Описание (необязательно)
5. Нажмите "Сохранить"
```

**Проблема:** Сейчас требуется вводить URL, а не загружать файл с компьютера.

**API endpoint для портфолио:**

```bash
# Загрузка фото в портфолио
curl -X POST https://aurelle.uz/api/upload/portfolio \
  -H "Cookie: connect.sid=ВАШ_SESSION_ID" \
  -F "image=@/путь/к/фото.jpg"

# Ответ:
# {"success":true,"url":"/uploads/portfolio/filename.jpg"}
```

## 🔧 Технические проблемы и решения

### Проблема 1: "404 Page Not Found" на /api/logout

✅ **ИСПРАВЛЕНО** (коммит `3d8566fd`)

- Endpoint добавлен
- Теперь можно корректно выйти из системы

### Проблема 2: "net::ERR_FAILED" ошибки

⚠️ Это связано с:

1. **Яндекс.Карты без API ключа** - добавьте ключ в `VITE_YANDEX_MAPS_API_KEY`
2. **Отсутствующие изображения** - если URL фото некорректный

### Проблема 3: Загрузка фото работает через URL, а не через файл

⚠️ **Нужно улучшить UI**

**Текущее состояние:**

- Backend API готовы и работают:
  - `/api/upload/salon-photo` ✅
  - `/api/upload/portfolio` ✅
  - `/api/upload/master-photo` ✅
  - `/api/upload/avatar` ✅

- Frontend показывает форму с URL input вместо file input

**Временное решение:**

1. Загрузите фото на любой хостинг (imgur.com, imgbb.com)
2. Скопируйте прямую ссылку на изображение
3. Вставьте URL в форму на сайте

**Или используйте API напрямую:**

```bash
# 1. Залогиньтесь на сайте
# 2. Откройте DevTools (F12)
# 3. Application → Cookies → найдите connect.sid
# 4. Скопируйте значение cookie

# 5. Загрузите фото через curl:
curl -X POST https://aurelle.uz/api/upload/salon-photo \
  -H "Cookie: connect.sid=ЗНАЧЕНИЕ_ИЗ_ШАГА_4" \
  -F "image=@/path/to/photo.jpg"

# 6. Получите URL фото в ответе
# 7. Используйте этот URL в форме на сайте
```

### Проблема 4: Запись на услугу не работает

⚠️ **Требуется проверка**

**Возможные причины:**

1. Салон не добавил услуги
2. Нет доступных мастеров
3. Не заполнены часы работы
4. JavaScript ошибка на фронтенде

**Проверка:**

```javascript
// Откройте консоль (F12) и проверьте:
fetch("/api/bookings", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  credentials: "include",
  body: JSON.stringify({
    salonId: "SALON_ID",
    serviceId: "SERVICE_ID",
    date: "2026-01-05",
    time: "14:00",
  }),
})
  .then((r) => r.json())
  .then(console.log)
  .catch(console.error);
```
