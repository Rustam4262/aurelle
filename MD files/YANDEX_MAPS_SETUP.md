# 🗺️ Настройка Яндекс.Карт для AURELLE

## Зачем нужен API ключ Yandex Maps?

API ключ необходим для отображения интерактивной карты на главной странице сайта, которая показывает расположение всех салонов красоты.

---

## 📋 Шаги по получению API ключа

### 1. Регистрация в Yandex Developer

1. Перейдите на https://developer.tech.yandex.ru/
2. Нажмите **"Войти"** в правом верхнем углу
3. Войдите через свой Яндекс аккаунт (или создайте новый)

### 2. Получение API ключа

1. После входа перейдите в раздел **"API"** → **"JavaScript API и HTTP Геокодер"**
2. Нажмите кнопку **"Получить ключ"** или **"Create API key"**
3. Заполните форму:
   - **Название**: `AURELLE Maps` (или любое другое)
   - **Домены**:
     - `localhost` (для локальной разработки)
     - `aurelle.uz` (для продакшена)
     - `*.aurelle.uz` (для поддоменов)
   - **Лимиты**: Оставьте значения по умолчанию (бесплатный тариф)
4. Нажмите **"Создать"**
5. Скопируйте полученный API ключ

---

## 🔧 Добавление ключа в проект

### Локальная разработка

1. Создайте файл `.env` в корне проекта (если его еще нет)
2. Добавьте строку:
   ```env
   VITE_YANDEX_MAPS_API_KEY=ваш-api-ключ-здесь
   ```
3. Перезапустите dev сервер:
   ```bash
   npm run dev
   ```

### Production (на сервере)

#### Вариант 1: Через .env файл (если не используете Docker)

```bash
ssh root@89.39.94.194
cd /var/www/aurelle
nano .env

# Добавьте строку:
VITE_YANDEX_MAPS_API_KEY=ваш-api-ключ-здесь

# Сохраните (Ctrl+O, Enter, Ctrl+X)
# Пересоберите проект:
npm run build
pm2 restart aurelle
```

#### Вариант 2: Через Docker (текущая настройка)

```bash
ssh root@89.39.94.194
cd /var/www/aurelle
nano docker-compose.yml

# В секции app -> environment добавьте:
VITE_YANDEX_MAPS_API_KEY: ваш-api-ключ-здесь

# Сохраните и перезапустите:
docker-compose down
docker-compose up -d --build
```

## ✅ Проверка работы

1. Откройте https://aurelle.uz в браузере
2. Прокрутите страницу вниз до секции **"Найдите салоны рядом"**
3. Карта должна загрузиться и показать:
   - Интерактивную карту Ташкента
   - Маркеры всех зарегистрированных салонов
   - Возможность увеличения/уменьшения масштаба
   - Клик по маркеру показывает информацию о салоне

### Если карта не загружается:

**Проверьте в консоли браузера (F12):**

- Есть ли ошибки связанные с Yandex Maps
- Правильно ли передается API ключ

**Частые проблемы:**

1. ❌ **"API key is invalid"**
   - Проверьте правильность API ключа
   - Убедитесь что домен добавлен в список разрешенных

2. ❌ **"Загрузка карты..."** не исчезает
   - API ключ не установлен
   - Добавьте `VITE_YANDEX_MAPS_API_KEY` в .env

3. ❌ **"Ошибка загрузки карты"**
   - Проблемы с сетью
   - API Яндекс.Карт недоступен
   - Превышен лимит запросов

### Лимиты бесплатного тарифа:

- ✅ 25,000 запросов в день

```

https://aurelle.uz
https://www.aurelle.uz
```

4. Смотрите статистику использования
