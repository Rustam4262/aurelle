# 🗺️ Активация Яндекс.Карт на Сервере

## ✅ Что уже сделано

Интеграция Яндекс.Карт уже реализована в коде! Карта будет автоматически отображаться на главной странице после добавления API ключа.

**Возможности:**

- ✅ Интерактивная карта на главной странице
- ✅ Автоматическое отображение всех салонов из БД
- ✅ Маркеры с информацией о салоне (название, рейтинг, город)
- ✅ Автоматическое центрирование и масштабирование
- ✅ Поддержка всех языков (EN/RU/UZ)
- ✅ Адаптивный дизайн
- ✅ Обработка ошибок

## 🚀 Активация в 3 шага

### Шаг 1: Получите API ключ (5 минут)

1. Откройте https://developer.tech.yandex.ru/
2. Войдите через Яндекс аккаунт
3. Перейдите: **API** → **JavaScript API и HTTP Геокодер**
4. Нажмите **"Получить ключ"**
5. Заполните:
   - Название: `AURELLE Maps`
   - Домены: `localhost`, `aurelle.uz`, `*.aurelle.uz`
6. Скопируйте полученный API ключ

### Шаг 2: Добавьте ключ на сервер

```bash
# Подключитесь к серверу
ssh root@89.39.94.194
# Пароль: w2@nT*6D

# Перейдите в директорию проекта
cd /var/www/aurelle

# Откройте docker-compose.yml
nano docker-compose.yml
```

Найдите секцию `app` → `environment` и добавьте строку:

```yaml
version: "3.8"
services:
  postgres:
    # ... postgres config ...

  app:
    build: .
    ports:
      - "5000:5000"
    environment:
      DATABASE_URL: postgresql://aurelle_user:w2@nT*6D@postgres:5432/aurelle
      SESSION_SECRET: ...
      NODE_ENV: production
      PORT: 5000
      GOOGLE_CLIENT_ID: ...
      GOOGLE_CLIENT_SECRET: ...
      YANDEX_CLIENT_ID: ...
      YANDEX_CLIENT_SECRET: ...
      # ДОБАВЬТЕ ЭТУ СТРОКУ:
      VITE_YANDEX_MAPS_API_KEY: ваш-api-ключ-здесь
    depends_on:
      - postgres
    restart: unless-stopped
```

Сохраните файл:

- Нажмите `Ctrl+O` (Save)
- Нажмите `Enter`
- Нажмите `Ctrl+X` (Exit)

### Шаг 3: Пересоберите и перезапустите

```bash
# Остановите контейнеры
docker-compose down

# Пересоберите и запустите
docker-compose up -d --build

# Проверьте статус
docker-compose ps

# Проверьте логи (опционально)
docker-compose logs app | tail -20
```

## ✅ Проверка работы

1. Откройте https://aurelle.uz в браузере
2. Прокрутите страницу вниз до секции **"Найдите салоны рядом"**
3. Должна загрузиться интерактивная карта с маркерами салонов

**Что вы должны увидеть:**

- ✅ Карта Ташкента (или другого города, где есть салоны)
- ✅ Фиолетовые маркеры на местах расположения салонов
- ✅ При клике на маркер - всплывающее окно с информацией
- ✅ Элементы управления картой (zoom, fullscreen, geolocation)

**Если карта не загружается:**

- Откройте консоль браузера (F12 → Console)
- Проверьте есть ли ошибки связанные с Yandex Maps
- Убедитесь что API ключ правильно добавлен в docker-compose.yml
- Проверьте логи: `docker-compose logs app | grep -i yandex`

## 📋 Альтернативный способ (без Docker rebuild)

Если хотите избежать полной пересборки Docker контейнера:

### Вариант A: Через .env файл внутри контейнера

```bash
ssh root@89.39.94.194
cd /var/www/aurelle

# Создайте .env файл если его нет
docker-compose exec app sh -c 'echo "VITE_YANDEX_MAPS_API_KEY=ваш-ключ" >> .env'

# Перезапустите только app контейнер
docker-compose restart app
```

### Вариант B: Пересоберите только клиентскую часть

```bash
ssh root@89.39.94.194
cd /var/www/aurelle

# Добавьте ключ в docker-compose.yml (как в Шаге 2)
nano docker-compose.yml

# Пересоберите и перезапустите
docker-compose up -d --build app
```

## 🔍 Отладка

### Проблема: "Ошибка загрузки карты"

**Причина:** API ключ не установлен или неверный

**Решение:**

```bash
# Проверьте что ключ добавлен в docker-compose.yml
docker-compose config | grep VITE_YANDEX_MAPS_API_KEY

# Если пусто - ключ не добавлен, вернитесь к Шагу 2
```

### Проблема: "API key is invalid"

**Причина:** Домен не добавлен в разрешенные

**Решение:**

1. Откройте https://developer.tech.yandex.ru/
2. Найдите ваш API ключ
3. Добавьте домены: `aurelle.uz`, `www.aurelle.uz`, `localhost`

### Проблема: Карта показывает только Ташкент, но без маркеров

**Причина:** В базе данных нет салонов с координатами

**Решение:**

1. Откройте панель владельца салона
2. При добавлении/редактировании салона убедитесь что:
   - Указан адрес
   - Указаны координаты (latitude/longitude)
3. Или добавьте координаты вручную в БД:

```bash
docker-compose exec postgres psql -U aurelle_user -d aurelle
UPDATE salons SET latitude = 41.2995, longitude = 69.2401 WHERE id = 1;
\q
```
