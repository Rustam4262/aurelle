## 🔍 Причина

**Отсутствовал критический API endpoint `/api/auth/user`**

Фронтенд пытался получить данные текущего пользователя, но endpoint не существовал. Это приводило к тому, что:

1. ✅ Пользователь успешно регистрировался
2. ✅ Пользователь успешно входил в систему
3. ❌ НО страница не могла определить что пользователь залогинен
4. ❌ Не показывалась форма заполнения профиля
5. ❌ Пользователь не мог попасть в кабинет

---

## ✅ Решение

### Добавлен endpoint `/api/auth/user`

**Файл:** `server/routes/auth.routes.ts`

**Что делает:**

- Проверяет есть ли активная сессия
- Возвращает данные текущего пользователя
- Или возвращает 401 если не залогинен

**Код:**

```typescript
router.get("/auth/user", (req: any, res) => {
  // Check if user is authenticated via session
  if (req.session && req.session.passport?.user) {
    const user = req.session.passport.user;
    return res.json({
      id: user.claims.sub,
      email: user.claims.email,
      firstName: user.claims.first_name,
      lastName: user.claims.last_name,
      profileImageUrl: user.claims.profile_image_url,
    });
  }

  // User not authenticated
  return res.status(401).json({ message: "Not authenticated" });
});
```
