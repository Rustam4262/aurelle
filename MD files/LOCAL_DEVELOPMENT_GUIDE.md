# AURELLE - Local Development Guide

Это руководство поможет вам запустить AURELLE платформу локально для тестирования и разработки.

## Требования

- **Node.js** >= 20.x
- **PostgreSQL** >= 14.x
- **npm** или **yarn**

## Быстрый старт (Windows)

### Вариант 1: Автоматический запуск

```bash
# Запустите скрипт
scripts\start-local.bat
```

Этот скрипт автоматически:
1. Проверит установку Node.js
2. Установит зависимости (если нужно)
3. Создаст тестовых пользователей
4. Запустит сервер разработки

### Вариант 2: Ручной запуск

```bash
# 1. Установите зависимости
npm install

# 2. Настройте .env файл (если еще не сделали)
# Убедитесь, что DATABASE_URL указывает на вашу локальную PostgreSQL базу

# 3. Создайте базу данных PostgreSQL
createdb aurelle

# 4. Примените схему базы данных
npm run db:push

# 5. Создайте тестовых пользователей
npx tsx scripts/create-test-users.ts

# 6. Запустите сервер разработки
npm run dev
```

## 🐛 Troubleshooting

### Ошибка: "Cannot connect to database"

**Решение:**
1. Убедитесь, что PostgreSQL запущен
2. Проверьте `DATABASE_URL` в `.env`
3. Создайте базу данных: `createdb aurelle`

### Ошибка: "Port 5000 already in use"

**Решение:**
1. Измените `PORT` в `.env` на другой (например, 5001)
2. Или остановите процесс, занимающий порт 5000

### Тестовые пользователи не созданы

**Решение:**
```bash
# Запустите скрипт вручную
npx tsx scripts/create-test-users.ts
```

### Ошибка: "Module not found"

**Решение:**
```bash
# Переустановите зависимости
rm -rf node_modules
npm install
```
