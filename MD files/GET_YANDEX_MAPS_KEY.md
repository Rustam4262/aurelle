## 📋 Получение API ключа (5 минут)

### Шаг 1: Регистрация

1. Откройте: **https://developer.tech.yandex.ru/**
2. Нажмите кнопку **"Войти"** в правом верхнем углу
3. Войдите через свой Яндекс аккаунт
   - Если нет аккаунта Яндекс - создайте на **https://passport.yandex.ru/**

### Шаг 2: Получение ключа

1. После входа вы окажетесь в консоли разработчика
2. В левом меню выберите: **"API"**
3. Найдите раздел: **"JavaScript API и HTTP Геокодер"**
4. Нажмите кнопку: **"Получить ключ"** или **"Create API key"**

### Шаг 3: Настройка ключа

При создании ключа заполните форму:

**Название проекта:**

```
AURELLE Beauty Salon Maps
```

**Разрешенные домены (важно!):**

```
localhost
aurelle.uz
www.aurelle.uz
*.aurelle.uz
```

**Описание (опционально):**

```
Interactive map for beauty salon locations
```

**Лимиты:**

- Оставьте значения по умолчанию
- Бесплатный тариф: 25,000 запросов/день (более чем достаточно)

### Шаг 4: Копирование ключа

1. После создания вы увидите ваш **API ключ**
2. Скопируйте его (выглядит примерно так: `abc123-def456-ghi789-jkl012`)
3. **Сохраните ключ в надежном месте** (понадобится для следующего шага)

## 🚀 Добавление ключа на сервер

### Способ 1: Через SSH (рекомендуется)

```bash
# 1. Подключитесь к серверу
ssh root@89.39.94.194
# Пароль: w2@nT*6D

# 2. Откройте docker-compose.yml
cd /var/www/aurelle
nano docker-compose.yml

# 3. Найдите строку (примерно на строке 18):
#    VITE_YANDEX_MAPS_API_KEY:
#
# 4. Замените на (вставьте ваш ключ):
#    VITE_YANDEX_MAPS_API_KEY: abc123-def456-ghi789-jkl012

# 5. Сохраните файл:
#    Ctrl+O (save)
#    Enter
#    Ctrl+X (exit)

# 6. Перезапустите контейнеры:
docker-compose down
docker-compose up -d --build

# 7. Проверьте статус:
docker-compose ps
docker-compose logs app | tail -20
```

### Способ 2: Быстрое обновление (без пересборки)

Если хотите избежать полной пересборки Docker:

```bash
ssh root@89.39.94.194
cd /var/www/aurelle

# Замените YOUR_API_KEY на ваш ключ:
sed -i 's/VITE_YANDEX_MAPS_API_KEY: $/VITE_YANDEX_MAPS_API_KEY: YOUR_API_KEY/' docker-compose.yml

# Перезапустите только app контейнер:
docker-compose up -d --force-recreate app
```

## 🔧 Возможные проблемы

### Проблема: "API key is invalid"

**Причина:** Домен не добавлен в разрешенные

**Решение:**

1. Откройте https://developer.tech.yandex.ru/
2. Найдите раздел **"Мои ключи"**
3. Выберите ваш ключ
4. Нажмите **"Редактировать"**
5. Убедитесь что добавлены домены:
   - `aurelle.uz`
   - `www.aurelle.uz`
   - `localhost` (для тестирования)

### Проблема: Карта показывает "Ошибка загрузки карты"

**Причина:** API ключ не добавлен или пустой

**Решение:**

```bash
ssh root@89.39.94.194
cd /var/www/aurelle

# Проверьте docker-compose.yml:
grep -A 2 VITE_YANDEX_MAPS_API_KEY docker-compose.yml

# Должно быть:
# VITE_YANDEX_MAPS_API_KEY: ваш-ключ
#
# А НЕ:
# VITE_YANDEX_MAPS_API_KEY:
```

### Проблема: Карта есть, но нет маркеров салонов

**Причина:** В базе данных нет салонов с координатами

**Решение:**

1. Откройте https://aurelle.uz/owner
2. Зарегистрируйтесь как владелец салона
3. Добавьте салон с указанием адреса
4. При редактировании салона добавьте координаты:
   - Latitude (широта): например `41.2995` (Ташкент)
   - Longitude (долгота): например `69.2401` (Ташкент)
