# 🏠 Запуск проекта AURELLE локально

Следуйте этим шагам, чтобы развернуть и запустить проект на своем компьютере.

## 1. Требования

Убедитесь, что у вас установлены:

- **Node.js** (версия 20 или выше)
- **PostgreSQL** (база данных)
- **Git**

## 2. Установка зависимостей

Откройте терминал в папке проекта (`d:\AURELLE`) и выполните:

```bash
npm install
```

## 3. Настройка Базы Данных

1. Убедитесь, что служба PostgreSQL запущена.
2. Создайте пустую базу данных (например, `aurelle_local`).
   - Через командную строку: `createdb aurelle_local`
   - Или через pgAdmin / DBeaver.

## 4. Настройка переменных окружения (.env)

Создайте файл `.env` в корне проекта и добавьте следующие настройки:

```ini
# Подключение к БД (замените user:password на ваши данные от PostgreSQL)
DATABASE_URL=postgresql://postgres:password@localhost:5432/aurelle_local

# Секрет для сессий (можно любой набор символов для локальной разработки)
SESSION_SECRET=local_dev_secret_key_123

# Режим разработки
NODE_ENV=development
PORT=5000
```

## 5. Применение схемы БД

Запустите миграции, чтобы создать таблицы в базе данных:

```bash
npm run db:push
```

## 6. Запуск

Запустите проект в режиме разработки:

```bash
npm run dev
```

Приложение будет доступно по адресу: `http://localhost:5000`
