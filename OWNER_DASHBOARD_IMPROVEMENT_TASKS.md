## 📊 Текущее состояние

Кабинет владельца салона ([owner.tsx](client/src/pages/owner.tsx)) включает:
- Список салонов владельца
- Календарь бронирований

## 🚀 Приоритетные задачи (P0)

### 1. Финансовая аналитика и отчетность
**Описание**: Добавить модуль финансовой отчетности для владельца
**Что включает**:
- Общая выручка (день/неделя/месяц/год)
- Выручка по услугам
- Выручка по мастерам
- График динамики доходов
- Средний чек
- Конверсия бронирований в завершенные услуги
- Экспорт отчетов в Excel/PDF

**Технические требования**:
- Новый эндпоинт: `GET /api/owner/analytics/revenue`
- Компонент: `<RevenueAnalytics />`
- Фильтры по датам, салонам, мастерам
- Кэширование через Redis

**Файлы для изменения**:
- `server/routes/owner.routes.ts`
- `client/src/components/revenue-analytics.tsx` (новый)
- `client/src/pages/owner.tsx`

### 2. Управление персоналом
**Описание**: Расширенное управление мастерами и сотрудниками
**Что включает**:
- Список всех мастеров по салонам
- Добавление/редактирование/удаление мастеров
- Установка графика работы мастеров
- Управление специализациями
- Загрузка портфолио мастеров
- Отслеживание рейтинга мастеров
- История работы мастера (количество услуг, выручка)

**Технические требования**:
- Эндпоинты:
  - `GET /api/owner/masters`
  - `POST /api/owner/masters`
  - `PUT /api/owner/masters/:id`
  - `DELETE /api/owner/masters/:id`
  - `GET /api/owner/masters/:id/stats`
- Компонент: `<MasterManagement />`
- Drag-and-drop для загрузки фото портфолио

**Файлы для изменения**:
- `server/routes/owner.routes.ts`
- `client/src/components/master-management.tsx` (новый)
- `client/src/pages/owner.tsx`
