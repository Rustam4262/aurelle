# Мессенджер AURELLE — первый этап

Реализован локально. На прод не опубликован, production-база не изменялась.

## Что работает

- Приватный маршрут /messenger с адаптивным списком чатов и открытой перепиской, RU/UZ/EN.
- Личные переписки между любыми зарегистрированными пользователями, независимо от роли. Одна переписка на пару аккаунтов, включая одновременное создание.
- Входы из кабинетов клиента, владельца, мастера, фриланс-мастера и администратора. «Мессенджер» заменяет название «Связь» у клиента.
- «Написать» в публичном профиле мастера, в профиле салона (пишет владельцу), в карточке клиента у салонного мастера.
- Поиск активных публичных мастеров/салонов. Клиентская база, телефоны и email в поиске не раскрываются. Для частного контакта доступна собственная ссылка в панели нового чата.
- Текст до 4000 символов, история с загрузкой ранних сообщений, непрочитанные, статусы «Отправлено»/«Прочитано».
- Обновление открытого чата каждые 5 секунд, списка каждые 15 секунд, счётчика в кабинете каждые 30 секунд. Это опрос API, не WebSocket и не push-уведомления.
- Доступ только участникам на всех операциях; CSRF; запрет заблокированным аккаунтам; ограничение частоты отправки; блокировка собеседника.
- Идемпотентная повторная отправка по clientId. Текст остаётся при ошибке сети, серверная история сохраняется после перезагрузки. Черновики между чатами сохраняются в памяти страницы, не после перезагрузки.

## Установка

Новая миграция migrations/0039_messenger.sql создаёт четыре таблицы без изменения существующих пользователей/записей. Перед будущим деплоем: резервная копия базы, применить именно эту миграцию один раз, проверить таблицы, затем переключить приложение и выполнить smoke-тест с двумя тестовыми аккаунтами. При откате приложения сохранять таблицы с переписками, не удалять сообщения.

Локальные тесты намеренно используют только 127.0.0.1:55439, отдельную схему messenger_test. Test HTTP server 127.0.0.1:55440 использует искусственную авторизацию только в scripts/test-messenger.ts; она не входит в production-сборку. Изолированный кластер: %TEMP%/aurelle-messenger-pg-20261005. Production .env тесты не загружают.
