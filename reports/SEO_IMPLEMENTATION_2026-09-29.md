# AURELLE: публичные SEO-страницы RU / UZ / EN

Дата: 29 сентября 2026. Релиз 20260929-seo-8c4e0ddb опубликован на https://aurelle.uz. Ниже сохранены результаты локальной подготовки; итог публикации приведён в конце.

## Готово

- Публичные главная, каталог, карточки салонов и самостоятельных мастеров, посадочные город + услуга имеют адреса /ru, /uz, /en.
- Сервер отдаёт готовый HTML: названия, услуги, цены, длительность, адреса, изображения и ссылки; в карточках также график, опубликованные отзывы и доступные мастера. Данные читаются из БД. Для людей и роботов используется один ответ, без определения User-Agent.
- Серверный первоначальный документ рендерится React renderToString; после загрузки JS его заменяет существующее интерактивное приложение. Это прогрессивное отображение публичных данных, не полная SSR-гидратация кабинетов или всей платформы. Бронирование по-прежнему требует JavaScript.
- Новые посадочные используют общий React-компонент на сервере и в браузере. Добавлены ссылки на реальные городские категории с главной и карточек салонов.
- Заголовки, описания, html lang, canonical, Open Graph, hreflang (ru/uz/en/x-default) согласованы на сервере и клиенте.
- Sitemap содержит только опубликованные публичные карточки и существующие посадочные во всех трёх языках. Нет авторизации, фильтрованного поиска и вымышленных lastmod.
- Старые публичные URL перенаправляются 301 в RU-версию. Query-параметры выбора услуги сохраняются. Переключатель языка сохраняет текущую страницу и параметры; навигация внутри приложения сохраняет выбранный язык.
- Кабинеты, авторизация, API и фильтрованный поиск имеют noindex. Неизвестные маршруты, отсутствующие/черновые/заблокированные карточки и пустые посадочные возвращают 404. Сбой БД при подготовке публичного документа — 503 и Retry-After.
- Данные HTML/JSON экранируются; в первоначальный документ не включаются email аккаунта, ID владельца, пароли, записи клиентов и переписка.
- Структурированные данные: BeautySalon/Person, реальные предложения, ItemList и BreadcrumbList. Рейтинги не выдумываются.
- Переход с услуги через вход сохраняет язык и выбранную услугу для салона; для самостоятельного мастера добавлено восстановление выбора из serviceId.

## Какие страницы существуют сейчас локально

После удаления тестовых данных sitemap содержит 30 URL, каждый проверен: HTTP 200.

Примеры (каждый существует с ru, uz, en):

- http://127.0.0.1:5000/en
- http://127.0.0.1:5000/en/search
- http://127.0.0.1:5000/en/tashkent/salons
- http://127.0.0.1:5000/en/tashkent/hair-care
- http://127.0.0.1:5000/en/tashkent/haircuts
- http://127.0.0.1:5000/en/tashkent/nail-services

Tashkent / Ташкент / Toshkent объединяются. Справочник содержит названия и варианты написания 13 городов Узбекистана; страницы создаются только при наличии активных услуг в опубликованных карточках. Незнакомые города требуют добавления в справочник shared/public-seo.ts.

Категории сопоставляются с сохранённой категорией услуги, без угадывания по названию. Например, nails даёт nail-services, но не manicure: последняя появляется только с услугой категории manicure. Смена данных действует при следующем серверном запросе; клиентский кеш документа — 30 секунд. Пустые сочетания не включаются в sitemap.

Интерфейс и системные тексты новых страниц переведены на три языка. Собственные описания салонов и услуг используют существующие поля переводов; при отсутствии перевода показывается доступный текст владельца. Адреса не переводятся автоматически. Качество и полноту контента должны поддерживать владельцы/редакторы; частотность поисковых запросов отдельно не исследовалась.
