# Исправление загрузки фото в портфолио мастера

## Проблема
Мастера не могли загружать фото в своё портфолио. При попытке загрузить фото и сохранить его с описанием, сервер возвращал ошибку 400 с сообщением "Invalid portfolio data".

## Причина
В файле [server/routes/masters.routes.ts:308](server/routes/masters.routes.ts#L308) валидация требовала полный URL (`z.string().url()`), но эндпоинт загрузки `/api/upload/portfolio` возвращал относительный путь типа `/uploads/portfolio/image_abc123.jpg`.

Это та же проблема, которая была с загрузкой фото салонов.

## Решение
Изменили валидацию с `z.string().url()` на `z.string().min(1)` чтобы принимать относительные пути.

### Изменённый код (server/routes/masters.routes.ts:308)
```typescript
// БЫЛО:
imageUrl: z.string().url().max(500),

// СТАЛО:
imageUrl: z.string().min(1).max(500), // Accept relative paths like /uploads/...
```
