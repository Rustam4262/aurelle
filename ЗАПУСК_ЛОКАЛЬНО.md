# 🚀 AURELLE - Локальный запуск платформы

## Системные требования
- Node.js 22.18.0+ ✅ (установлено)
- pnpm 10.28.2+ ✅ (установлено)

## Способ 1: Запуск через batch файл (Windows)

Просто двойной щелчок на файле:
```
D:\AURELLE\start-dev.bat
```

Или через cmd.exe:
```cmd
cd D:\AURELLE
start-dev.bat
```

## Способ 2: Прямой запуск через PowerShell

```powershell
cd D:\AURELLE
.\node_modules\.bin\tsx watch server/index.ts
```

## Способ 3: Через pnpm (если работает)

```powershell
cd D:\AURELLE
pnpm dev
```

## Что происходит при запуске?

1. **TypeScript компилируется** через tsx watch
2. **Express сервер** запускается на порту **5000**
3. **Vite dev server** интегрируется для клиентской части
4. **Hot reload** активирован - изменения в коде применяются автоматически

## После запуска

Откройте в браузере:
```
http://localhost:5000/
```

Или проверьте статус:
```
http://localhost:5000/api/health
```

## Что доступно?

✅ **Главная страница** - http://localhost:5000/  
✅ **Поиск** - http://localhost:5000/search  
✅ **О платформе** - http://localhost:5000/about  
✅ **API салонов** - http://localhost:5000/api/salons  
✅ **Robots.txt** - http://localhost:5000/robots.txt  
✅ **Sitemap** - http://localhost:5000/sitemap.xml  

## Остановка сервера

- **Ctrl + C** в терминале
- Или закройте окно терминала

## Возможные проблемы

### Порт 5000 занят?
```powershell
# Измените PORT в .env файле и перезагрузитесь
$env:PORT = 3000
```

### Нет пакетов?
```powershell
cd D:\AURELLE
pnpm install
```

### Ошибки компиляции TypeScript?
```powershell
# Очистите кэш
rm -r dist
```
